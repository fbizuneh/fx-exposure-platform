## app/ (composition)
**Runtime (decision 0023): `npm run start` runs one server process (migrations, HTTP health routes, an event-delivery loop and a due-cycle loop); see app/README.md.** `app/src/compose.ts` builds all services over one database; `app/src/dispatch.ts` delivers events between them (`drain`) and starts due cycles (`startDueCycles`). `app/src/end-to-end.db.test.ts` runs a cycle through the real services (no fakes). The dispatcher sends every `<service>.change-recorded` event to Audit. It also routes cycle approved to FX Trade (release gate) and cycle skipped or deleted (cancels drafts). A real process still needs a loop that calls both on a timer.

## Release 1 stream J

J1 control totals by currency is merged (decision 0031): `controlTotals(tenant, batchId)` on Data Source's contract, computed on read (measured at 13–16 ms for 20,000 rows and 40 currencies, well under the 500 ms budget), and an optional `expectedTotals` on `GlBatch` that refuses a batch whose totals do not match. D7 (loader `--control`) is built on top of it. J2 audit records for Data Source and Exposure Analysis is merged (decision 0032): Data Source records `batch.loaded`, `mapping-rule.added` and `mapping-rule.ended` for a person, same shape as Master Data and FX Rate; a connector feed and a duplicate record nothing. Exposure Analysis has no person-triggered command (every one of its commands is called only by the dispatcher, reacting to another service's event), so it records nothing — found and confirmed, not invented. Still not recorded (found, not fixed, per the J file): FX Rate's `setStaleAfter`/`setPreferredSource`/`setPivotCurrency`/`setOutlierShare` and Master Data's `setMaxEndShare` take no actor. J3 stuck-event permissions are proposed (decision 0030): `operations:manage-events` (TREASURY_ADMIN, platform role), and `listDeliveryProblems`/`deliveryProblemSummary`/`retryDeliveryProblem` in `app/src/operations.ts`, guarding `dispatch.ts`'s unguarded primitives. A retry resets the event and announces `<service>.change-recorded` (`event.retried`, target `stuck-event`/the plain event ID, `fields: []`) in the *same transaction*, through that service's own outbox — durable by construction (confirmed with the product owner after review). That announcement alone (not change records generally) is exempt from the usual tenant/service delivery-ordering hold, so it still reaches Audit even if the retried event gets stuck again; every other event, including ordinary audit records, keeps the existing order (decision 0012 point 4). `app/`'s `/status` route is unchanged (no actor yet; stream C).

## Facts the code depends on
- The product owner's workbook (Exposure Calculation Steps) and the Hedging Programs domain design are the references for exposure rules; they win over earlier defaults.
- GL balances: no source record ID (identity is entity, account, currency, dimensions); the sign is kept exactly as sent and carries no asset or liability meaning; the period is the as-of date; the filter needs both the FX-relevant and the monetary flag.
- Amounts: rounded to 2 places per row, shown with 0 decimals by clients. Pairs follow market convention (EUR, GBP, AUD, NZD, USD, CHF, CAD, SGD, then alphabetical).
- Exposure currency, first match wins: portfolio level (non-portfolio currency); a level with an entity (the entity's non-functional currency); the program override; the default (NDF, then USD, EUR, GBP, AUD, NZD, CAD, CHF, SGD, then currency 2).
- FX Trade: every pre-trade has a unique reference (PT- plus 12 characters) sent in the outbound file and echoed back; it is the main match key. Executed trades are append-only versions; a match is a link; fills are recomputed from current live versions; a trade with no or unknown program is stored unmatched; matching is exact with no tolerance.
- Not built yet: hedge rows and net exposure (with FX Trade), forecast and AR/AP adapters, netting by product/project/business unit.

## Working notes
- TypeScript runs on Node 22 type stripping: `import type`, `.ts` extensions, no parameter properties. `import { Decimal } from "decimal.js"` (named).
- Services import others only through `@services/<name>/contract`; the schema check flags any text like `<otherSchema>.` in code, so do not name a variable `identity.`.
- DB tests need `TEST_DATABASE_URL` (database name ends `_test`) and run one file at a time (`--test-concurrency=1`). A throwaway PostgreSQL 16 can be started with `pg_ctl` on a spare port; CI uses 17.
- Push with `git -c push.negotiate=true push`; the token has no `workflow` scope, so workflow files change by hand.
- Design documents also live in Claude Docs; the data ownership table exists in both places and must be kept in step.
